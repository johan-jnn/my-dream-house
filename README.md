# My Dream House

A small website with a cool repo to show off our ci and collaboration skills

## Stack

- [Vite](https://vite.dev/)
- [VueJS](https://vuejs.org/)
- [TailwindCSS](https://tailwindcss.com/)

## Installation

```sh
# Replace bun with your favorite package manager
bun install
bun run dev --open
```
